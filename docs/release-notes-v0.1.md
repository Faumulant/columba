# Columba（飞鸠）v0.1

仅局域网的跨设备文件投递工具。配对一次，此后右键「发送到某设备」即可，不经云、无账号。

## 下载

| 文件 | 说明 |
|---|---|
| `Columba-0.1-setup.exe` | **推荐**。一键安装器，双击即装（无需管理员） |
| `dropw.exe` | 后台服务单独文件（安装器已含，仅手动部署时需要） |
| `drop.exe` | 命令行工具（配对/发送/排障） |
| `SHA256SUMS.txt` | 校验和，用于核对下载完整性 |

## 安装

1. 双击 `Columba-0.1-setup.exe`
2. 若出现「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
   （安装包未做代码签名，SmartScreen 会对所有新发布的小众软件这样提示）
3. 向导里保持勾选「注册防火墙规则」，随后在弹出的管理员确认中点「是」
   —— 这一步让同一局域网内的其他设备能发现本机
4. 装完托盘出现鸠的图标即表示后台已在运行

**卸载**：设置 → 应用 → Columba（或开始菜单里的「卸载 Columba」）。
卸载时会询问是否同时删除本机数据（设备身份、已配对设备、传输历史），
默认保留——这样重装后不需要重新配对。

## 快速上手

1. 右键托盘图标 → 打开面板 → 「添加设备」生成 6 位配对码
2. 另一台设备输入该配对码完成配对（一次性，此后互相信任）
3. 右键任意文件 → 发送到 → 你的设备

浏览器里也能用：面板「设置 → 浏览器扩展」按提示加载扩展，
之后网页里右键即可把页面、选中文字、链接、图片、视频发到设备。

## 本次内容

首个版本。桌面端（Windows）与安卓端功能完整：

- 局域网自动发现（UDP 组播 + 单播心跳兜底），无需配置 IP
- TLS 1.3 双向证书认证，配对码只作一次性授权凭证
- 流式传输 + `.part` 暂存 + 双端 SHA-256 校验 + 原子改名
- 同名文件自动改名（`photo.jpg` → `photo (1).jpg`），**绝不静默覆盖**
- 传输进度（面板顶栏圆环 / 安卓列表圆环），支持取消
- 传输历史（记录对端设备 ID，对方改名后旧记录跟随）
- 右键「发送到」菜单按已配对设备自动维护
- 浏览器扩展（Chrome / Edge / Firefox）：右键发送页面/文字/链接/图片/视频
- 安卓端：五分类列表、自动/手动保存、前台服务常驻接收

## 已知限制

- **仅局域网**：不做中继，跨网段 / 跨 NAT 不通
- **安装包未签名**：SmartScreen 与部分杀软会提示（见安装第 2 步）
- **断点续传未实现**：中断即整传重试
- **仅 Windows 桌面端**：macOS / Linux / iOS 未实现
- 正式版 Firefox 无法安装未签名扩展，需 Developer Edition
